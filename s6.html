🚦 Misión 6: Tomar decisiones (if)

🎯 Hoy aprenderás a…
  • escribir condiciones con ==, !=, <, >, <=, >=
  • usar if, elif y else
  • respetar los dos puntos y la sangría

📖 Teoría exprés

Un programa puede decidir qué ejecutar según se cumpla una condición. Es el «si… si no» de los bloques.

SímboloSignifica
==es igual a
!=es distinto de
< >menor / mayor que
<= >=menor o igual / mayor o igual
  • Ojo: = guarda un valor; == compara.
  • Después de la condición van dos puntos : y las instrucciones sangradas (4 espacios o tabulador).
  • elif (de «else if») añade más condiciones; else recoge todo lo demás.
  • % da el resto de una división: 7 % 2 vale 1. Un número es par si n % 2 == 0.

🔍 Ejemplos

if / else

edad = int(input("¿Cuántos años tienes? "))
if edad >= 18:
    print("Eres mayor de edad")
else:
    print("Eres menor de edad")
¿Cuántos años tienes? 14
Eres menor de edad

if / elif / else

nota = int(input("Nota: "))
if nota >= 9:
    print("Sobresaliente")
elif nota >= 5:
    print("Aprobado")
else:
    print("Suspenso")
Nota: 6
Aprobado
