🎤 Misión 5: Hablar con el usuario (input)

🎯 Hoy aprenderás a…
  • pedir datos con input()
  • convertir texto a número con int() y float()
  • crear programas interactivos

📖 Teoría exprés

Hasta ahora los datos los poníamos nosotros. Con input() el programa pregunta al usuario y guarda lo que escribe.

  • nombre = input("¿Cómo te llamas? ") guarda lo escrito en la variable.
  • input siempre devuelve texto (str), aunque escribas un número.
  • Para calcular hay que convertir: int(...) para enteros, float(...) para decimales.
  • Se suele escribir junto: edad = int(input("Edad: ")).

🔍 Ejemplos

Saludo

nombre = input("¿Cómo te llamas? ")
print("¡Hola, " + nombre + "!")
¿Cómo te llamas? Ana
¡Hola, Ana!

Un número

edad = int(input("¿Cuántos años tienes? "))
print("El año que viene tendrás", edad + 1)
¿Cuántos años tienes? 14
El año que viene tendrás 15

El error de olvidar int()

edad = input("Edad: ")
print(edad + 1)
TypeError: can only concatenate str (not "int") to str

🚀 Misión de entrega

Cabina de comandos

Crea tarea5.py con tres programas interactivos:

  1. Presentación. Pregunta el nombre y el color favorito y muestra, por ejemplo: A Ana le gusta el azul.
  2. Calculadora. Pide dos números enteros y muestra su suma, su resta y su producto.
  3. Conversor. Pide una cantidad en euros (puede tener decimales) y muéstrala en dólares. Guarda el cambio en una variable: cambio = 1.08.
