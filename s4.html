🎒 Misión 4: La mochila de datos (variables)

🎯 Hoy aprenderás a…
  • guardar datos en variables
  • distinguir números y textos
  • hacer cálculos con variables
  • cambiar el valor de una variable durante el programa

📖 Teoría exprés

Una variable es una caja con nombre donde el programa guarda un dato. Se crea con el signo = (que significa «guarda esto aquí»).

TipoQué guardaEjemplo
intNúmeros enterosvidas = 3
floatNúmeros con decimales (con punto)precio = 2.5
strTexto, entre comillasnombre = "Lucía"
  • Operaciones: + suma, - resta, * multiplica, / divide.
  • Con print puedes mezclar textos y variables separándolos con comas: print("Tengo", vidas, "vidas").
  • Una variable puede cambiar: vidas = vidas - 1 lee «mi nueva vidas es la antigua menos 1».
  • Nombres: sin espacios ni tildes, que expliquen qué guardan (precio, no x).

🔍 Ejemplos

Variables y print

nombre = "Lucía"
edad = 14
print("Hola,", nombre)
print("El año que viene tendrás", edad + 1, "años")
Hola, Lucía
El año que viene tendrás 15 años

Una variable que cambia

vidas = 3
vidas = vidas - 1
print("Te quedan", vidas, "vidas")
Te quedan 2 vidas

Cuidado: mezclar texto y número con +

print("Tengo " + 5)
TypeError: can only concatenate str (not "int") to str

🚀 Misión de entrega

La tienda de gadgets

Crea el archivo tarea4.py con tres programas seguidos, separados por un comentario con su número.

  1. Tienda. Guarda en variables el nombre de un producto, su precio (15) y las unidades (4). Muestra el producto y el total a pagar.
  2. Rectángulo. Guarda base = 8 y altura = 5. Muestra el perímetro y el área.
  3. Videojuego. Empieza con puntos = 100. Gana 50 puntos, después pierde 30. Muestra los puntos finales (cambiando la variable en cada paso).

Generaliza: cambia solo los valores de las variables (precio, base, puntos…) y comprueba que tus programas siguen dando el resultado correcto.
